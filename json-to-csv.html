FAQ

Common questions

What JSON structure works best for CSV conversion?
CSV conversion works best with a JSON array of objects where each object has the same keys — like a database table or API list response. Example: [{"name":"Alice","age":30},{"name":"Bob","age":25}]. Each key becomes a column header; each object becomes a row.
What happens to nested objects?
Nested objects and arrays are JSON-stringified and placed as text in their cell. For example, "address": {"city": "Delhi"} becomes "{""city"":""Delhi""}" in the CSV. If you need nested data as separate columns, flatten the JSON first.
Can I open the CSV in Excel or Google Sheets?
Yes. The downloaded .csv file opens directly in Excel, Google Sheets, LibreOffice Calc, or Apple Numbers. Values are properly quoted and escaped, with correct line endings (CRLF) for Windows and web compatibility.
Can I also convert CSV back to JSON?
Yes! JSON Studio also supports CSV to JSON conversion. Just paste your CSV data in the input panel and select the CSV → JSON mode in the toolbar.
